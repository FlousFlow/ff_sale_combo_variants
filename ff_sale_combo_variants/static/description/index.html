Stop Managing Combo Variants Manually

Smart Combo Variant Sources replaces the tedious work of adding every product variant as a Combo Choice item. Add the Product Template once, choose a Variant Mode, and let the sync engine keep every combo choice up to date — automatically and idempotently.

🧩 Variant Modes

  • Single Variant — exactly one variant (classic behavior)
  • All Variants — every active variant of the template becomes a valid choice
  • Selected Variants — tick only the variants you allow

⚡ Automatic Targeted Sync

  • New variants are added to linked combo choices automatically
  • Archived variants are removed from new sales — historical orders stay intact
  • 100% idempotent: sync 10 times, zero duplicates
  • Hourly safety-net cron + manual "Sync Variants Now" button

🛒 Hierarchical Sales UX

Instead of a flat list of 100 variants, the salesperson first picks the Product Template (e.g. Pepsi, Lenovo ThinkPad), then selects the attributes (Size, Color, RAM…) through the standard product configurator, and the system resolves the combination to the real product.product. Delivery, invoicing and COGS follow the standard Odoo flow.

💰 Flexible Pricing

  • Default extra price per source
  • Per-variant price overrides
  • Standard combo proration keeps prices consistent

🛡️ Safety First

  • No core modification — model/view/controller inheritance + OWL patch only
  • Existing (manual) combos keep working 100% unchanged
  • Generated items are read-only and traceable to their source
  • Multi-company safe, least-privilege access rights
  • Source deletion blocked when referenced by historical sale orders

📌 Configuration

Menu: Sales → Configuration → Products → Smart Variant Sources
Requires Variant Sources: Manager rights (implied: Product Manager).

🚀 Installation

  1. Install sale_management (Sales) — included in standard Odoo
  2. Add this module to your addons path
  3. Update Apps list and install Smart Combo Variant Sources
  4. Grant the Variant Sources: Manager group to product administrators

✅ Quality

12 automated tests covering all variant modes, auto-sync, idempotency, archiving, manual-item isolation, multi-company and the full quotation flow.
